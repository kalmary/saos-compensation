# Extraction performance

1. **Locate and validate the target first — implemented.** Embeddings select the highest-scoring judgment/request sentences at cosine >= 0.7. Judgment is mandatory; request is optional. Basal resolves amounts and multiple recipients afterward, summing a case-level target and exposing injured_party_count before feature inference. Reject cases with missing, invalid or insufficiently confirmed targets before processing their paragraphs.
2. **Combine short paragraphs into larger blocks — implemented.** Pack adjacent paragraphs into bounded inputs while preserving source offsets and complete sentences. Increasing the current character limit alone does not combine short paragraphs. Current extraction uses source-aligned batches up to 6000 characters, starting with factual findings and revisiting other passages only for missing fields. A local paired mini/4.5B inspection is stored under tmp/basal_comparison_v10; independent quality validation remains pending.
3. **Extract candidates without classifying every paragraph — implemented.** Extract feature candidates directly from the larger blocks, retain their source sentences, and check factuality and target leakage only for candidate sentences. Preserve confidence thresholds, missing-value handling and rejection of unsafe evidence. The default workflow now skips preliminary paragraph/block classification. Final candidates additionally require field-relevance review, with shared source checks across fields. Local model-call/time comparisons do not replace an independently labeled evaluation.
