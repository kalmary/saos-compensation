Kwoty, wynik sprawy lub uzasadnienie wysokości — także bez liczby.

14 / ZAPIS

Przyjęcie rekordu nie oznacza jeszcze poprawnej etykiety

WARUNKI

  • Co najmniej jedno źródłowo potwierdzone pole tekstowe.
  • Kontrola trafności i wycieku dla każdego wypełnionego opisu.
  • W trybie zwykłym: rozpoznany, dopuszczalny cel.

PLIKI

record.json — wartości cech

award.json — total + valid

Tylko debug: source.txt + model_calls.json

Zapis przypadku → Aktualizacja checkpointu → Następny wyrokPo przerwaniu wracamy do utrwalonego postępu.

Debug może zachować nierozwiązany cel jako valid=false. Nie omija wymogu poprawnego opisu. Polityka oddalenie → 0 zł wymaga wdrożenia.

15 / WNIOSKI

Mamy kontrolowany proces. Potrzebujemy pomiaru jakości.

01

MiniLM rozpoznaje kontekst. Cel to odczytana kwota albo 0 zł przy oddaleniu.

02

Basal wydobywa dowody i ocenia ich przydatność.

03

Przed treningiem trzeba ręcznie sprawdzić reprezentatywną próbę.
